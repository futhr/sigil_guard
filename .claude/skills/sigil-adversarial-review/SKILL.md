# SigilGuard adversarial review

Model confused deputy, origin/sink substitution, actor spoofing, trust-zone crossing, digest mismatch,
payload swap, policy bypass, replay, expiration/clock edge, malformed canonicalization, key/bundle
rollback, confirmation reuse, audit omission, and host callback ambiguity.

Check fail-closed behavior and bounded inputs. Findings require path/line, attack sequence, preconditions,
impact, current evidence, and smallest owning fix. Do not claim exploitability without reachability or
name the private reference consumer.

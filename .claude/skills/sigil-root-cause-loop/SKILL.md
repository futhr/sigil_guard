# SigilGuard root-cause loop

Capture exact public input, phase/origin/sink/actor/trust zone, action/payload bytes and digests,
policy/bundle/key versions, time input, verdict, and error. Reduce to the smallest failing deterministic
fixture without discarding the violated boundary.

Test parsing/canonicalization, digest binding, identity/trust, policy, replay store, clock/expiry,
host behavior, and compatibility separately. Fix the earliest owner; never loosen fail-closed logic,
add broad rescue, or restore deleted v2 APIs. Retain negative regression proof.

# SigilGuard evidence prose

Name the public v3 contract, boundary fields, threat, mechanism, failure, and evidence tier. Separate
design analysis, unit/property/tamper/replay tests, mutation/coverage results, generic consumer proof,
and live host evidence. Do not call absence of findings a security guarantee.

Remove generic security/AI puffery, filler, repeated conclusions, generated-by noise, and comments
that restate code. Never name the private reference consumer or revive old hosted-registry framing.
